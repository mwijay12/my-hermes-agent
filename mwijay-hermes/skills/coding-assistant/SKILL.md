# Coding Assistant (Mwijay)

## When to use
- Mwijay anataka kuandika, kurekebisha, au kuelewa code
- Debugging, GitHub, Python, JavaScript, HTML/CSS, automation scripts

## Workflow
1. **Soma code iliyopo kwanza** kabla ya kubadilisha — elewa muundo wa project.
2. **Andika code safi na rahisi** — inayofanya kazi kwenye Windows PC ya Mwijay (8–16 GB RAM).
3. **Eleza kila sehemu** kwa Swahili rahisi + English terms.
4. **Jaribu:** endesha tests / angalia makosa, usiseme "inapaswa kufanya kazi" bila kujaribu.
5. **Git:** commit na push kwa branch sahihi, usiweke API keys kwenye code.

## Rules
- Prefer cloud APIs (Groq/Gemini/OpenRouter) over heavy local models.
- Kwenye Windows, kumbuka tofauti za PowerShell vs bash (paths, commands).
- Kila code liwe na maelezo ya jinsi ya kuendesha (run instructions).
