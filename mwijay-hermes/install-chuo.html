Sakinisha Mwijay AI kwenye PC ya Chuo

Mwongozo huu umeandikwa kwa hali halisi ya maabara: huna ruhusa za msimamizi (admin), hakuna Git, na mtandao unaweza kuwa umezuiwa. Njia zote hapa zinafanya kazi ndani ya folda yako ya mtumiaji pekee.

Ujumbe muhimu kwanza: kusakinisha Hermes na kusakinisha utambulisho wa Mwijay AI ni vitu viwili. Hermes ndiyo injini (inatoka kwa mradi mkuu); Mwijay AI ni rangi, jina, sauti, na misemo yako (folda ya mwijay-hermes/ iliyo kwenye repo yako). Kwa kuwa mabadiliko yako yamekwishaunganishwa kwenye main, njia zote mbili zinakupa toleo lako lilelile.

3) Njia ya haraka (Windows) — amri moja

Fungua PowerShell (si Command Prompt) na endesha:

powershell -ExecutionPolicy Bypass -File "$HOME\my-hermes-agent\mwijay-hermes\scripts\install-chuo.ps1"

Hilo linafanya kila kitu: kukagua mazingira, kupata repo (clone au ZIP), kusakinisha, na kuweka utambulisho wako. Lakini script bado haipo kwenye PC yako mara ya kwanza — kwa hivyo chagua moja kati ya hizi:

3.1 Kama una Git

git clone https://github.com/mwijay12/my-hermes-agent "$HOME\my-hermes-agent"
powershell -ExecutionPolicy Bypass -File "$HOME\my-hermes-agent\mwijay-hermes\scripts\install-chuo.ps1"

3.2 Kama huna Git (pakua ZIP kwanza)

  1. Fungua kiungo hiki kwenye kivinjari → ZIP itapakuliwa.
  2. Ifungue (right-click → Extract All) → hamishia folda inayoitwa my-hermes-agent ndani ya C:\Users\<jina lako>\.
  3. Kisha endesha kwenye PowerShell:
powershell -ExecutionPolicy Bypass -File "$HOME\my-hermes-agent\mwijay-hermes\scripts\install-chuo.ps1"
Kama PowerShell inasema "running scripts is disabled": hiyo ndiyo sababu ya -ExecutionPolicy Bypass kwenye amri zilizo hapo juu — inalazwa tu kwa script hii, na haihitaji admin. Usibadili ExecutionPolicy ya kompyuta nzima (na usiwahi kuendesha Set-ExecutionPolicy Unrestricted kwenye PC ya chuo).

3.3 Script inakuuliza maswali

  • "Njia: SOURCE au OFFICIAL?" — inachagua yenyewe kulingana na Python uliyo nayo. Unaweza kulazimisha: -Method official au -Method source.
  • "Endelea na --apply? (Y/N)" — kwanza inakuonyesha kausa kavu (hakibadilishi chochote), kisha inakuuliza. Jibu Y.

4) Kama upo kwenye Linux/WSL ya maabara

bash ~/my-hermes-agent/mwijay-hermes/scripts/install-chuo.sh
# au bila Python sahihi:
bash ~/my-hermes-agent/mwijay-hermes/scripts/install-chuo.sh --official

Script hii inatumia curl na (hiari) unzip. Kama huna Git wala unzip, pakua ZIP kwa kivinjari kwanza.

5) Weka funguo zako (API keys)

Hii ndiyo hatua ya mwisho — na ndiyo pekee inayohitaji uamuzi wako. Hermes haitafanya kazi bila angalau key moja.

  1. Fungua mwijay-hermes/config/.env.free.example kwenye repo — ina majina yote ya funguo za bure.
  2. Chagua providers 2–3 (Groq na Gemini ni rahisi zaidi; zote hazihitaji kadi).
  3. Tengeneza faili C:\Users\<jina lako>\.hermes\.env na uweke funguo zako hivi:
GROQ_API_KEY=gsk_...
GEMINI_API_KEY=AIza...
OPENROUTER_API_KEY=sk-or-v1...

Kisha pima:

python mwijay-hermes\scripts\check_free_keys.py

Viungo vya kupata kila key vipo kwenye free-providers.html. Usinakili funguo za watu wengine — zinafutwa haraka, na si halali.

6) Thibitisha kwamba imekaa sawa

hermes doctor              # inakuambia nini hakipo
hermes skin                # lazima uone "mwijay" na "mwijay-mwanga"
hermes bundles list        # lazima uone /mwijay
hermes model               # chagua provider/model
python mwijay-hermes\scripts\preview_skin.py mwijay    # ona mwonekano
hermes chat                # anza!
Ukiona "hermes: command not found": njia ya source inaweka Hermes ndani ya .venv ya repo. Tumia .venv\Scripts\hermes.exe, au ongeza kwenye PATH ya mtumiaji wako: 
[Environment]::SetEnvironmentVariable("Path", $env:Path + ";$HOME\my-hermes-agent\.venv\Scripts", "User")
Funga na ufungue upya PowerShell baada ya hapo.

8) Kabla hujaondoka kwenye PC ya chuo ⚠️

PC za chuo ni za watu wengi. Funguo zako ni kama manenosiri — mtu akizipata anatumia akaunti yako ya Groq/Gemini/OpenRouter (na kama umeweka kadi popote, zinaweza kugharimu pesa).

powershell -ExecutionPolicy Bypass -File "$HOME\my-hermes-agent\mwijay-hermes\scripts\install-chuo.ps1" -Wipe

Hii inafuta .hermes\.env na .env.free.example. Pia:

  • Usihifadhi funguo kwenye kivinjari (password manager ya shule, notepad kwenye desktop, n.k.).
  • Usiziweke kwenye picha/screenshot.
  • Fungua free-providers.html — kuna viungo vya kufuta funguo kabisa kwenye akaunti za providers kama hutaki zitumike tena.
  • Ukitaka kuondoa Hermes kabisa: futa folda %LOCALAPPDATA%\hermes na %USERPROFILE%\my-hermes-agent.
