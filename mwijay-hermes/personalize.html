1) Anza kwa kuona (kabla ya kubadilisha chochote)

Hiki ndicho chombo kipya: kinaonyesha kamili jinsi terminal itakavyoonekana — nembo, paneli ya majibu, spinner, mistari ya tools, na rangi zote — bila kugusa config.yaml wala ~/.hermes.

python3 mwijay-hermes/scripts/preview_skin.py mwijay            # terminal nyeusi
python3 mwijay-hermes/scripts/preview_skin.py mwijay-mwanga     # terminal nyeupe
python3 mwijay-hermes/scripts/preview_skin.py --list            # orodha ya skins
python3 mwijay-hermes/scripts/preview_skin.py mwijay --width 80 # jaribu upana mwingine

Nembo kuu (MWIJAY AI kwa herufi kubwa) inaonekana tu kama terminal yako ina upana wa angalau kolamu 95 — vinginevyo Hermes inaonyesha nembo ya mlima peke yake.

2) Sakinisha (amri moja)

# Kwanza onyesha tu (hakibadilishi chochote):
python3 mwijay-hermes/scripts/setup_personal.py

# Kisha tekeleza:
python3 mwijay-hermes/scripts/setup_personal.py --apply

# Kwa terminal yenye background nyeupe:
python3 mwijay-hermes/scripts/setup_personal.py --apply --skin mwijay-mwanga

Inafanya mambo matano, na kila moja ni salama kurudia:

  1. Skins → ~/.hermes/skins/mwijay.yaml (+ mwijay-mwanga.yaml)
  2. Bundle → ~/.hermes/skill-bundles/mwijay.yaml (amri /mwijay)
  3. Profile → SOUL.md, USER.md, MEMORY.md (haziguswi kama zipo tayari)
  4. Misemo ya Kiswahili → ~/.hermes/status_phrases/mwijay.yaml
  5. config.yaml → inaongeza display.skin, display.personality, display.status_phrases, na skills.external_dirs. Haifuti chochote — inaweka nakala config.yaml.bak kwanza, na hairudii thamani ulizoweka mwenyewe.

Kwenye Windows tumia python ileile inayoendesha hermes (inahitaji pyyaml, ambayo hermes tayari inayo): python mwijay-hermes\scripts\setup_personal.py --apply

Ikiwa tayari una config.yaml nzuri na hutaki script iiguse: nakili tu faili kwa mkono — skins/, skill-bundles/, status_phrases/ — na uongeze mstari mmoja kwenye config: display: {skin: mwijay}. Hiyo inatosha kubadilisha rangi.

Rangi zote ziko kwenye faili la skin. Ukitaka tofauti, hariri hapa na uendeshe tena kionjo. Huna haja ya kuanzisha upya chochote.

Rangi yoyote usiyotaja inarithiwa kutoka skin ya default ya Hermes — kwa hivyo skin yako inaweza kuwa na mistari mitatu tu ukipenda.

5) Telegram inasema Kiswahili sasa

Hermes inatuma maneno mafupi kama "still working…" wakati kazi ni ndefu. Nimekuwekea misemo 44 ya Kiswahili (mwijay-hermes/status_phrases.yaml):

bado nipo, naendelea
inachukua muda kidogo, bado inaendelea
sijakwama, bado inaendesha
hakuna jibu bado, bado nasubiri
nipe sekunde
karibu tumemaliza

Setup inaiweka kwenye ~/.hermes/status_phrases/mwijay.yaml na kusanidi display.status_phrases.mode: replace (Kiswahili pekee). Ukitaka zichanganywe na zile za Kiingereza, badilisha kuwa append.

6) Ziada ndogo zinazoleta ladha

Pet / Mascot

Kiumbe kinachoitikia kile agent anachofanya — na unaweza kukizalisha kwa maelezo:

/hatch kaduka ndogo ya dhahabu yenye mbawa, imevaa skafu ya bendera ya Tanzania

Au: hermes pets list → hermes pets install <jina> --select. Mapambo tu, hayaathiri tokeni.

Amri yako

/mwijay inapakia skills zako zote tano mara moja. Na ukitaka Hermes tofu kabisa yenye jina lako:

hermes profile create mwijay
mwijay setup && mwijay chat

Sauti yake

/personality mwijay. Una saba tayari kwenye config: mwijay, mwijay_teacher, mwijay_coder, mwijay_business, helpful, concise, technical.

Kumbukumbu

SOUL.md (yeye ni nani), USER.md (wewe ni nani), MEMORY.md (anachokumbuka). Mwambie tu: "kumbuka kwamba…" — au yazihariri mwenyewe.

7) Kilichobaki (tulichoahirisha)

  • Computer use — ipo tayari kwenye repo na inafanya kazi kwenye Windows (hermes computer-use install). Tunaweza kuifanya baadaye; inakula tokeni nyingi, kwa hivyo ni vizuri kwanza uwe na rotation ya providers ikifanya kazi.
  • App binafsi — hatujengi. Ukurasa huu ndio "app" yako sasa: terminal inayoitwa Mwijay AI, Telegram kwa mobile. Ukibadili mawazo baadaye, njia fupi ni kupamba PWA ya hermes dashboard (saa 1–3, hakuna kupakia).

8) Muhtasari wa amri

# Ona na usakinishe
python3 mwijay-hermes/scripts/preview_skin.py mwijay
python3 mwijay-hermes/scripts/setup_personal.py --apply

# Badilisha wakati wowote
hermes skin mwijay | mwijay-mwanga | default | ares | poseidon
hermes config                 # rekebisha display kwa UI ya maandishi
/personality mwijay           # ndani ya chat
/mwijay                       # pakia skills zote
/hatch <maelezo>              # zalisha pet yako

# Thibitisha
hermes skin                   # orodha ya skins
hermes bundles list           # lazima uone /mwijay
hermes pets doctor            # hali ya pet
python3 mwijay-hermes/scripts/check_free_keys.py
Kumbusho moja tu la usalama: funguo zibaki kwenye .env (~/.hermes/.env au %LOCALAPPDATA%\hermes\.env), kamwe kwenye Git. setup_personal.py hailazimishwi kugusa .env wala funguo zako — inanakili faili za muundo pekee.
