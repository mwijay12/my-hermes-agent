Kutoka Hermes kwenye terminal → Computer Use (anadhibiti PC yako) → Mobile → na mwisho app yako binafsi kabisa. Kila ngazi imeandikwa na amri halisi, gharama, na tahadhari. Vyote unavyoviona hapa vipo ndani ya repo hii tayari — hakuna cha kubuni.

1) Ngazi ya Terminal — ifanye iwe yako (bila kugusa code)

Hii ndiyo "Hermes thing on Terminal" uliyosema. Haibadili tabia ya agent — inabadili jinsi inavyoonekana na kukuita. Hermes inatenganisha mambo haya vizuri sana:

  • Personality — jinsi anavyoongea (tayari una mwijay).
  • Skin — rangi, spinner, nembo, jina linaloonekana.
  • SOUL / USER / MEMORY — yeye ni nani, wewe ni nani, na anakumbuka nini.
  • Skills + Bundles — ujuzi wake, na amri moja ya kuwapakia wote.
  • Profile — Hermes tofu kabisa, na amri yake yenyewe.

1.1 Skin ya Mwijay (rangi za bendera ya Tanzania)

Nimekuwekea skins mbili kwenye mwijay-hermes/skins/:

FailiKwa ajili yaRangi
mwijay.yamlTerminal yenye background nyeusi (default ya Windows Terminal / PowerShell / WSL)Dhahabu #FCD116 · Kijani #1EB53A · Buluu #00A3DD
mwijay-mwanga.yamlTerminal yenye background nyeupe/angavuVilevile, lakini vimekoza ili visomeke kwenye nyeupe
 
hermes skin mwijay            # badili mara moja
hermes skin                   # ona orodha ya skins zote
# au weka kwenye config.yaml:
display:
  skin: mwijay

Kila skin inabadilisha: rangi 20, nyuso za spinner ((⚕) (☀) (✦)), vitenzi vya Kiswahili ("inafikiria", "inatafiti"…), jina Mwijay AI, ujumbe wa kukaribisha, nembo ya maandishi, na emoji za kila tool.

1.2 Pet / Mascot yako

Hermes ina pets — kiumbe kidogo kinachocheza kwenye terminal, TUI na desktop app; kinaitikia kile agent anachofanya (anafikiria, anatumia tool, amemaliza, ameshindwa). Na cha kushangaza: unaweza kumzalisha mwenyewe kwa maelezo ya maandishi:

/hatch kaduka ndogo ya dhahabu yenye mbawa, imevaa skafu ya rangi ya bendera ya Tanzania
# au:
hermes pets list              # orodha ya gallery
hermes pets install boba --select
hermes pets show              # onyesha uhuishaji (Ctrl+C kuacha)
hermes pets scale 0.7         # ipunguze ukubwa
hermes pets off               # izime

Ni mapambo tu — hayaathiri tokeni wala tabia ya agent, na imezimwa kwa default.

1.3 Sauti na utu (personality)

/personality mwijay           # au tayari imewekwa kwenye config.yaml
hermes config                 # rekebisha kwa UI ya maandishi

Una personalities 7 kwenye config yako: mwijay, mwijay_teacher, mwijay_coder, mwijay_business, helpful, concise, technical. Ongeza nyingine kama mwijay_biashara_ng au mwijay_haraka kwa mtindo wowote unaotaka.

1.4 Kumbukumbu yake (SOUL / USER / MEMORY)

Faili hizi tatu ndizo zinazomfanya awe wako, si wa mtu mwingine. Zipo tayari kwenye mwijay-hermes/profile/. Mwambie moja kwa moja: "kumbuka kwamba mimi ni…", "usisahau kwamba…" — au yaandike mwenyewe.

FailiInasema niniMfano wa kuongeza
SOUL.mdYeye ni nani, anavyoongea, mipaka yake"Usitumie lugha ya shule; ongea kama rafiki wa tech."
USER.mdWewe ni nani"Nina duka la…, nafanya kazi na…, napenda majibu mafupi saa za asubuhi."
MEMORY.mdAnachokumbuka kuhusu kazi zako"Mradi wa X ulianza 2026-11; kikomo cha Groq kilinikwaa mara 3."

1.5 Amri yako mwenyewe: /mwijay

Bundle ni amri moja inayopakia skills kadhaa kwa pamoja. Nimekuwekea mwijay-hermes/skill-bundles/mwijay.yaml inayopakia skills zote tano zako (allrounder, swahili-english, coding-assistant, business-content, research-learning) pamoja na maelekezo mafupi kuhusu PC yako.

hermes bundles list           # thibitisha /mwijay upo
/mwijay                       # ndani ya chat — inapakia zote mara moja
hermes bundles create ...     # tengeneza bundle lako jingine

1.6 Sanidi yote kwa amri moja tayari

# Kwanza onyesha tu (hakibadilishi chochote):
python3 mwijay-hermes/scripts/setup_personal.py

# Ukiona ni sawa, tekeleza:
python3 mwijay-hermes/scripts/setup_personal.py --apply

# Kwa terminal angavu:
python3 mwijay-hermes/scripts/setup_personal.py --apply --skin mwijay-mwanga

Inafanya: kunakili skins + bundle + SOUL/USER/MEMORY kwenda HERMES_HOME, na kuongeza display.skin na skills.external_dirs kwenye config.yaml (ikiweka nakala ya akiba config.yaml.bak kwanza). Ni salama kurudia mara mbili — haitarudia kazi iliyofanyika.

Kwenye Windows tumia python ileile inayoendesha hermes (inahitaji pyyaml, ambayo hermes tayari inayo):
python mwijay-hermes\scripts\setup_personal.py --apply

1.7 Profile — Hermes ya pili, na amri yake yenyewe

Hii ndiyo hatua kubwa zaidi ya "ubinafsishaji wa kweli": profile ni nyumba tofauti kabisa — config yake, keys zake, skills zake, kumbukumbu yake, sessions zake.

hermes profile create mwijay
mwijay setup                  # weka keys na model kwa profile hii
mwijay chat                   # sasa una amri inayoitwa "mwijay"
mwijay gateway start          # na gateway yake yenyewe

Unaweza kuwa na mwijay (yako binafsi), kazi (ya ofisi), research (ya kusoma tu). Hazichanganyikani.

1.8 Mambo mengine madogo yenye ladha

  • hermes --tui — badala ya CLI ya kawaida, tumia TUI (React+Ink) yenye paneli na uteuzi wa puku. Weka display.interface: tui kwenye config iwe default.
  • hermes hooks — endesha script yako kabla/baada ya kila zana (mfano: chelezo, arifa, kusafisha).
  • hermes cron — ratiba: "kila asubuhi saa 2 niletee muhtasari wa habari za tech + mawazo ya biashara".
  • hermes insights, hermes journey, hermes memory-graph — ona jinsi muda na kumbukumbu yako zinavyotumika.

2) Ngazi ya Computer Use — aachiye mikono (bila kukunyang'anya puku)

Hermes ina computer use iliyojengwa ndani: anabonyeza, anaandika, anasogeza, anasoma skrini. Tofauti na zana nyingi kama hizi, inafanya kazi nyuma ya pazia (background): puku yako haisogei, keyboard haichukuliwi, na madirisha hayaruki juu. Na haitegemei mfano maalum wa Anthropic — model yoyote yenye uwezo wa tools inaweza kuiendesha, hata ya bure.

2.1 Washa

hermes computer-use install      # inapakua cua-driver (Windows: install.ps1)
hermes computer-use status       # thibitisha
hermes computer-use doctor       # inakuambia ruhusa gani inakosekana
hermes tools                     # au wezesha kwa menyu: "🖱️ Computer Use"
MfumoJinsi inavyosoma skriniJinsi inavyobonyezaRuhusa unazohitaji
Windows (yako)UIAutomationSendInput + PostMessage — bila kuiba focusHakuna wakati wa kusakinisha
macOSAX (SkyLight)SLPSPostEventRecordTo (pid-scoped)Accessibility + Screen Recording
LinuxAT-SPIXTest / virtual-keyboardDISPLAY au Wayland + AT-SPI

2.2 Kwa nini "background mode" ni muhimu kwako

Una PC moja yenye RAM 8–16 GB. Njia nyingine za computer-use hunyang'anya puku na keyboard — huwezi hata kuandika wakati agent anafanya kazi. Hii hairuhusu hilo: unaweza kuendelea na kazi yako huku Mwijay AI akifanya yake kwenye dirisha lingine.

2.3 Mawazo ya kuifanyia kazi (yaliyochaguliwa kwa mazingira yako)

Asubuhi — "Briefing ya Mwijay"

Cron saa 6:30 → anafungua browser, anasoma vyanzo vyako, anatengeneza muhtasari wa Kiswahili (tech + biashara + Tanzania), anakuletea kwenye Telegram.

Kazi za kurudia rudia

Kujaza fomu za mtandaoni, kupakua statements, kupanga faili za folda, kuhamisha data kutoka tovuti kwenda Excel — kazi zinazokuchosha.

Utafiti wa soko

"Nenda kwenye tovuti hizi 10, linganisha bei za X, njoo na jedwali." Anafanya mwenyewe, anakuletea jedwali.

Msaada wa mbali kwa familia

Hii ni hatari — usifanye isipokuwa kwenye mashine tofauti. Tazama tahadhari hapa chini.

Computer use inakula tokeni nyingi sana. Kila hatua inatuma picha ya skrini (au mti wa vipengele). Kwa maana hiyo, mnyororo wa free-LLM tulioujenga kwenye free-providers.html ni muhimu sana hapa — utakwama mara moja ukitumia provider mmoja. Pia inahitaji modeli yenye vision (kuona picha) kwa matokeo bora zaidi: Gemini Flash (bure, 1M context) au NVIDIA NIM (bure) ni chaguo zuri la kuanzia.

2.4 Tahadhari (soma hii kabla ya kumpa mikono)

  • Tumia Windows account ya pili kwa majaribio makubwa — siyo ile unayotumia kila siku.
  • Benki, malipo, na akaunti nyeti — usimpe. Hata kama inawezekana, hatari yake ni kubwa kuliko faida.
  • Weka approval mode (hermes approvals) — iombe ruhusa kabla ya hatua hatarishi.
  • Picha za skrini huondoka kwenye PC yako kwenda kwa provider wa LLM. Kama skrini yako ina taarifa za mtu mwingine, hiyo ni faragha yake pia.
  • Anza na kazi ndogo zinazoweza kurudishwa nyuma (kufungua ukurasa, kunakili maandishi), kabla ya zile zisizoweza (kutuma ujumbe, kufuta faili).

3.1 Njia ya haraka zaidi: Telegram

hermes gateway setup           # chagua Telegram
# (utaulizwa bot token kutoka @BotFather)
hermes gateway start

Kidokezo: platform_toolsets kwenye config.yaml inakuwezesha kuamua ni zana zipi zinaruhusiwa kwenye Telegram (mfano: usimpe terminal kwenye simu ikiwa PC yako haipo karibu).

3.2 Dashboard kama app (PWA) — hatua kwa hatua

  1. Kwenye PC: hermes dashboard → inafungua bandari 9119.
  2. Sakinisha Tailscale kwenye PC na simu (bure kwa matumizi binafsi) — inakupa njia salama bila kufungua bandari kwenye router.
  3. Kwenye simu: fungua http://<pc-tailscale-ip>:9119 → menyu ya kivinjari → "Ongeza kwenye Skrini ya Nyumbani".
  4. Sasa una ikoni ya Mwijay AI kwenye simu, inayofunguka bila mipaka ya kivinjari.
Usiwahi kufungua bandari 9119 kwenye intaneti ya wazi. Dashboard ina ruhusa ya kuendesha terminal kwenye PC yako — mtu yeyote anayeifikia anamiliki mashine yako. Tumia Tailscale (au VPN yako) pekee. Pia weka nenosiri la dashboard ikiwa imewezeshwa.

3.3 Termux (Android) — Hermes halisi mfukoni

pkg update && pkg install -y git python clang rust make pkg-config libffi openssl nodejs ripgrep ffmpeg
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
# kisha: hermes setup  &&  hermes chat

Inafanya kazi: CLI kamili, cron, terminal/PTY, MCP, Telegram gateway, Honcho memory, ACP.
Haifanyi kazi vizuri bado: voice (ctranslate2 haina Android wheels), Playwright/browser, Docker. Na Android inaweza kusimamisha kazi za nyuma — kwa hivyo gateway inaweza kukatika (Tier 2, "best effort").

Ujanja: sakinisha Termux:Widget → unaweka njia za mkato kwenye skrini ya nyumbani ya simu, kama vile "Muhtasari wa asubuhi" au "Nakili kilichoko kwenye clipboard". Hiyo ni app yako ya kwanza, bila kuandika code.

3.4 Arifa (ntfy) — Mwijay akuite

Unganisha na hermes cron: kila kazi inapokwisha, piga notisi kwenye simu. Hii ndiyo inayofanya mambo yawe hai — huna haja ya kumsubiri.

4) Ngazi ya App — je, tujenge app yako binafsi?

Ndiyo, inawezekana — na kuna njia tatu, kutoka rahisi hadi kubwa. Kabla ya kuchagua, ukweli mmoja muhimu: Hermes inakuja na app ya desktop iliyojengwa kwa Electron (React + TypeScript), iko kwenye apps/desktop/ ndani ya repo hii. Kwa hivyo huanzii sifuri.

ChaguoUnachofanyaMudaFaidaHasara
A. PWA (inayopendekezwa kuanza) anza hapa Tumia hermes dashboard na uipambe: jina, ikoni, rangi, na "ongeza kwenye skrini ya nyumbani". Saa 1–3 Inafanya kazi mara moja kwenye simu na PC; hakuna kupakia (packaging); inabaki ikisawazishwa na repo juu. Sio ".exe" halisi; inahitaji PC iwe imewashwa.
B. Rebrand app ya desktop Nakili apps/desktop → badilisha jina (Mwijay AI), ikoni, rangi, maandishi ya kwanza, na default config yako (skin, provider, profile). Siku 2–5 Dirisha halisi, ikoni kwenye taskbar, tray, masasisho — "app yangu" kwa maana kamili. Unabeba mzigo wa kufuatilia mabadiliko ya repo juu kila update.
C. App ndogo ya simu (mpya kabisa) React Native / Expo inayozungumza na API ya gateway (/api), siyo na Python moja kwa moja. Wiki 2–4 App ya kweli kwenye Play Store / sideload; inafanya kazi simu ikiwa peke yake. Kazi kubwa zaidi; lazima usimamishe server (au PC) yenye Hermes.

4.1 Njia B — unachobadilisha hasa (rebrand)

apps/desktop/
  package.json          # name / productName / version / appId
  assets/icon.png       # ikoni ya programu (tengeneza 512x512)
  assets/icon.ico       # Windows
  assets/icon.icns      # macOS
  electron-builder.*    # jina la .exe, mchapishaji (publisher), appId
  src/...               # maandishi ya onboarding, majina kwenye UI

Halafu, ili iwe yako kweli, badilisha pia mambo haya ya ndani:

  • Default profile/config: ielekeze kwenye profile ya mwijay, iwasha skin ya mwijay, na itumie mnyororo wako wa fallback_providers tulioujenga.
  • Onboarding: badala ya "chagua provider", iwe "Karibu Mwijay AI — weka funguo zako za bure" na viungo vya free-providers.html.
  • Auondoe chapa ya Nous kutoka kwenye maandishi yanayoonekana (banner, About, links) — ila usiiondoe kwenye LICENSE/credits: bado ni kazi yao, na leseni ni MIT, hivyo kuibinafsisha ni halali.
Tahadhari kubwa kabla ya kuchagua njia B: app ya desktop ina kisakinishi chake cha masasisho (auto-update) kinachovuta toleo jipya kutoka kwa mradi mkuu. Ukibadilisha jina na ikoni, masasisho yanaweza kurudisha chapa ya juu au kuvunja mabadiliko yako. Zima auto-update kabla ya kusambaza, au shikilia masasisho kwa mikono kupitia git.

6) Tahadhari za mwisho

  • Funguo (keys) zibaki kwenye .env, kamwe kwenye Git. Repo hii ina .gitignore inayozuia .env — usiiondoe.
  • Computer use ni kumpa mtu funguo za nyumba. Anza kidogo, weka mipaka, usimpe benki.
  • Usifungue dashboard kwenye intaneti ya wazi. Tumia Tailscale au VPN.
  • Token ya bot ya Telegram ni kama nenosiri — usiiweke kwenye picha wala kwenye chat.
  • Chelezo: hermes backup kabla ya majaribio makubwa, hasa kabla ya kusanidi profile mpya au kuhariri config kwa mikono.
