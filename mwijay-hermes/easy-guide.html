Sehemu ya 1 — Hermes Agent ni nini?

Fikiria hivi

ChatGPT ni kama mshauri wa simu: unauliza, anajibu, hakumbuki kesho.

Hermes ni kama mfanyakazi unayemleta nyumbani kwako: anakaa kwenye PC yako, anatumia folda zako na terminal yako, anakumbuka ulichomwambia jana, na baada ya kazi ngumu anaandika daftari lake la maelekezo (skills) ili asifanye makosa yaleyale kesho. Tena unaweza kuongea naye kutoka Telegram au WhatsApp ukiwa safarini.

Tofauti na chatbot ya kawaida

Chatbot ya kawaidaAnajibu tu. Hakumbuki. Hafanyi kitu kwenye PC yako.
Hermes AgentAnaendesha command, anafungua na kuandika faili, anatafuta mtandaoni, anapanga ratiba (cron), anakumbuka, na anajifunza mwenyewe.
Model gani?Unachagua wewe: Groq, Gemini, OpenRouter, Nous Portal, au hata model ya local. Unaibadilisha kwa hermes model bila kugusa code.

Amri muhimu (copy-paste tu)

# Anza kuongea (terminal) hermes # Chagua model / provider (Groq, Gemini, OpenRouter) hermes model # Sanidi kila kitu kwa mara moja (wizard) hermes setup # Unganisha Telegram / WhatsApp / Discord hermes gateway setup hermes gateway start # Angalia kama kila kitu kiko sawa hermes doctor

Ndani ya mazungumzo: /new anza upya /model jina badilisha model /personality mwijay weka tabia ya Mwijay AI /skills ona skills /retry rudia jibu /undo futa hatua ya mwisho /compress punguza mazungumzo

Bonus: Nous Portal (hiari)

Badala ya kukusanya API key tano tofauti (model, utafutaji, picha, sauti, browser), Nous Portal inakupa zote kwa usajili mmoja: model 300+, web search, image generation, TTS, cloud browser. hermes setup --portal. Bado unaweza kutumia Groq/Gemini zako bure ukitaka.

Sehemu ya 2 — Kimi K3 "in C" maana yake nini?

Fikiria hivi

Kimi K3 ni kama injini ya ndege kubwa yenye vipande trilioni 2.78. Kawaida injini kama hiyo inahitaji kiwanda kizima — server kubwa na GPU nyingi (kadi za maelfu ya dola).

Mradi huu umeandika injini hiyo kwa lugha ya C (lugha ya zamani, ya chini kabisa, yenye nguvu) — bila Python, bila GPU, bila framework. Ujanja wake: haisomi injini nzima mara moja. Kila inapotaka kutoa neno moja, inatumia vipande 16 tu kati ya 896 (vinaitwa "experts"), na inavisoma moja kwa moja kutoka diski.

Ndiyo maana inafanya kazi na RAM ndogo kama GB 8 — lakini inahitaji diski kubwa sana, na ni polepole kwa sababu diski ni polepole kuliko RAM.

Kumbuka: “neno” hapa ni "token" (kipande cha neno). Sentensi ya maneno 20 inaweza kuchukua dakika 2 hadi 9.

Kwa nini sio kwa PC yako ya kila siku?

  • Diski haitoshi. PC yako ni chini ya TB 1, lakini model peke yake ni TB 1.56 — na unahitaji TB 1.7 za nafasi wazi. Haiingii kabisa.
  • Ni polepole sana. Hata kama ingeingia, ungesubiri sekunde 5–26 kwa kila neno. Hermes anahitaji majibu ya haraka ili afanye kazi nyingi (coding, utafiti, automation).
  • Ni programu ya command-line, sio API. Hermes hawezi kuizungumza moja kwa moja — ingehitaji "bridge" (na bado polepole).

    • Hitimisho: Kimi K3 ni funzo zuri la uhandisi na mradi wa kujivunia — sio msaidizi wako wa kila siku.

    Lakini unaweza kuijaribia (njia mpya kwenye repo)

    Watu wengi waliuliza: “vipi kama nina diski ya TB 1 tu?” Sasa kuna download-model.sh --layers N — inapakua vipande vya baadhi tu ya "layers" badala ya model nzima, na inakuambia wazi wazi matokeo sio Kimi K3 kamili. Ni majaribio tu ya kuona injini inavyofanya kazi.

    # 1. Jaribu bila kupakua chochote (chini ya dakika moja) git clone https://github.com/FareedKhan-dev/kimi-k3-in-c.git cd kimi-k3-in-c make -j make test # 2. Angalia kama PC yako inaweza (inapima RAM na diski) ./scripts/k3-doctor.sh # 3. Pakua sehemu tu (badala ya 1.56 TB) — MAJARIBIO export HF_TOKEN=hf_xxxxx ./scripts/download-model.sh ~/k3model --layers 2 # 4. Endesha ./bin/k3 ~/k3model --trunk ~/k3trunk --preset laptop \ --tok ~/k3model --prompt "The capital of France is" --gen 8 --incremental

    Kwenye Windows inafanya kazi kwa kutumia MSYS2 / MinGW-w64 (Git Bash). Hatua ya 1 peke yake haina haja ya model wala mtandao.

    Sehemu ya 4 — Kuanzisha Mwijay AI kwenye PC yako

    1. Sakinisha Hermes (PowerShell)
      iex (irm https://hermes-agent.nousresearch.com/install.ps1)

      Inasakinisha Python 3.11, Node, Git Bash, ripgrep, ffmpeg — hauitaji haki za Admin kwa mengi. Ikiwa antivirus (Bitdefender/Defender) itazuia uv.exe, ni false positive — iongezee exception kwenye folda ya bin.

    2. Pata API keys BURE
      Geminiaistudio.google.com/apikey — free tier kubwa, inaelewa Kiswahili vizuri
      Groqconsole.groq.com/keys — kasi ya ajabu, nzuri kwa coding. Sasa ni provider rasmi kwenye repo yako (iliongezwa kwenye commit ya leo)
      OpenRouteropenrouter.ai/keys — model 300+, free models pia

      Ziweke kwenye faili la %LOCALAPPDATA%\hermes\.env — kamwe usiziweke GitHub.

    3. Nakili utambulisho wa Mwijay AI
      Copy-Item .\mwijay-hermes\profile\SOUL.md "$env:LOCALAPPDATA\hermes\SOUL.md" -Force Copy-Item .\mwijay-hermes\profile\USER.md "$env:LOCALAPPDATA\hermes\USER.md" -Force Copy-Item .\mwijay-hermes\profile\MEMORY.md "$env:LOCALAPPDATA\hermes\MEMORY.md" -Force Copy-Item .\mwijay-hermes\config\config.yaml "$env:LOCALAPPDATA\hermes\config.yaml" -Force Copy-Item .\mwijay-hermes\skills\* "$env:LOCALAPPDATA\hermes\skills\" -Recurse -Force

      Hizi ndizo zinamfanya aitwe Mwijay AI, aongee Kiswahili chako, na akukumbuke.

    4. Anza kuongea
      hermes # kisha ndani ya mazungumzo: /personality mwijay
    5. (Hiari) Unganisha Telegram
      hermes gateway setup hermes gateway start

      Baada ya hapo unamzungumza Mwijay AI kutoka simu yako, hata ukiwa mbali na PC.
