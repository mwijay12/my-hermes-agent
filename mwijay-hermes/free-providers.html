Free LLM API Providers — Orodha ya Mwijay AI

Orodha ya providers wanaotoa API keys bila malipo, ili uweze kuzungusha (“rotation”) akili ya Hermes bila kulipa. Imekusanywa Novemba 2026 — viwango vya bure hubadilika, kwa hivyo fuata kiungo cha “Pata Key” kupata namba za sasa.

Kabla ya yote (muhimu): usitumie API keys za watu wengine.

Kutafuta keys zilizovuja kwenye GitHub na kuzitumia si “bure” — ni kuvunja sheria za matumizi ya provider, mara nyingi ni kosa la kisheria (kutumia kompyuta bila ruhusa), na keys hizo hufutwa haraka au huambatana na akaunti ya mtu mwingine (unaweza kuona data zake). Zaidi ya hayo: ukifanya hivyo akaunti yako ya GitHub na IP yako zinaweza kufungwa. Hivyo mwongozo huu hauhusishi kuvuna keys za watu — unakuonyesha jinsi ya kupata keys zako mwenyewe za bure, halali, na kuzizungusha.

3) Config tayari — nakili na ubandike

3.1 Funguo (weka kwenye .env, si config.yaml)

Tumia faili mwijay-hermes/config/.env.free.example iliyo kwenye repo hii — ina majina yote ya env variables.

3.2 config.yaml — providers wa custom + mnyororo wa fallback (rotation)

Hii ndiyo inayoipa Hermes “ubongo unaozunguka”: ikikwama kwa provider mmoja (rate limit / hitilafu), inaendelea na mwingine moja kwa moja bila kupoteza mazungumzo.

# --- Providers wa "custom" (OpenAI-compatible) ---
providers:
  inception:
    name: "Inception Mercury"
    api: "https://api.inceptionlabs.ai/v1"
    key_env: INCEPTION_API_KEY
    default_model: "mercury-3"
    models: ["mercury-3", "mercury-2", "mercury-coder-small"]
    transport: chat_completions

  agnes:
    name: "Agnes AI"
    api: "https://apihub.agnes-ai.com/v1"
    key_env: AGNES_API_KEY
    default_model: "agnes-2.0-flash"
    transport: chat_completions

  cerebras:
    name: "Cerebras"
    api: "https://api.cerebras.ai/v1"
    key_env: CEREBRAS_API_KEY
    default_model: "gpt-oss-120b"
    transport: chat_completions

  sambanova:
    name: "SambaNova"
    api: "https://api.sambanova.ai/v1"
    key_env: SAMBANOVA_API_KEY
    default_model: "Meta-Llama-3.3-70B-Instruct"
    transport: chat_completions

  github-models:
    name: "GitHub Models"
    api: "https://models.github.ai/inference"
    key_env: GITHUB_TOKEN
    default_model: "openai/gpt-4o-mini"
    transport: chat_completions

  llm7:
    name: "LLM7.io"
    api: "https://api.llm7.io/v1"
    key_env: LLM7_API_KEY
    default_model: "gpt-oss-20b"
    transport: chat_completions

# --- Mnyororo wa fallback: akili inayozunguka ---
# Jaribu kwa mpangilio; inapokwama (rate limit/4xx/5xx) inaendelea na ifuatayo.
model:
  provider: "groq"
  default: "openai/gpt-oss-120b"

fallback_providers:
  - provider: "cerebras"
    model: "gpt-oss-120b"
  - provider: "opencode-zen"
    model: "deepseek-v4-flash-free"
  - provider: "nvidia"
    model: "z-ai/glm-5.2"
  - provider: "inception"
    model: "mercury-3"
  - provider: "github-models"
    model: "openai/gpt-4o-mini"
  - provider: "gemini"
    model: "gemini-3.8-flash"
  - provider: "openrouter"
    model: "nvidia/nemotron-3-ultra-550b-a55b:free"
  - provider: "llm7"
    model: "gpt-oss-20b"
Kidokezo: unaweza pia kuweka mnyororo huu kwa njia ya mazungumzo — andika hermes fallback kwenye terminal na uchague kutoka kwenye menyu. Na kuona ni provider gani anayeishi kwa sasa: hermes model.

4) GitHub — njia mbili halali za kuitumia

A. GitHub Models (bure, key yako mwenyewe)

Endpoint https://models.github.ai/inference — unatumia Personal Access Token yako ya GitHub (permission models:read). Hakuna kadi, hakuna usajili mpya.

Kikomo: tier ya chini 15 RPM / 150 req-siku, tier ya juu 10 RPM / 50 req-siku, 8,000 tokeni kuingia / 4,000 kutoka kwa kila ombi. Inafaa kwa majaribio, si kwa mzigo mkubwa.

Tengeneza PAT →

B. Orodha inayosasishwa kila siku kwenye GitHub

open-free-llm-api/awesome-freellm-apis — zaidi ya API 134 za bure kutoka providers 40+, ikiwa na base URL, viwango vya bure na viungo vya keys. Inasasishwa kila siku.

Ukitaka kutafuta mwenyewe kwenye GitHub, tumia maneno kama: free llm api awesome list, openai compatible free inference, free tier api keys 2026 — na chuja kwa “Recently updated”.

5) Zidisha uwezo: funguo nyingi kwa provider mmoja (“credential pool”)

Huu ndio ujanja mkubwa zaidi. Kuna aina mbili za “kuzungusha”:

  • Cross-provider failover (fallback_providers) — provider mmoja akikwama, nenda kwa mwingine. Hii ndiyo tuliyosanidi sehemu ya 3.2.
  • Same-provider rotation (credential pool) — ndani ya provider mmoja, Hermes inazungusha funguo zako. Hii inajaribiwa kwanza, kabla ya kwenda kwa provider mwingine.

Kwa hiyo: ukifungua akaunti mbili au tatu za Groq (barua pepe tofauti), unapata mara mbili/mara tatu ya kikomo cha bure — na Hermes inazungusha yenyewe:

# Ongeza key ya pili / ya tatu kwa provider yuleyule
hermes auth add groq      --api-key gsk_ya_akaunti_ya_pili
hermes auth add openrouter --api-key sk-or-v1_ya_akaunti_ya_pili
hermes auth add gemini    --api-key AIza_ya_akaunti_ya_pili

# Angalia hali ya pools
hermes auth list

# Mkakati wa kuchagua key (hiari, kwenye config.yaml)
credential_pool_strategies:
  groq: round_robin      # zunguka sawasawa
  openrouter: least_used # chagua isiyotumika sana

Mikakati: fill_first (default), round_robin, least_used, random. Kumbuka: kila key mpya ina prompt cache yake, kwa hivyo kuzungusha katikati ya mazungumzo marefu kunasoma historia nzima kwa bei kamili mara moja.

6) Angalia kama keys zako zinaishi

Nimekuwekea script: mwijay-hermes/scripts/check_free_keys.py. Inasoma .env yako na kupima kila provider (model moja, ombi fupi), kisha inachapa jedwali:

python3 mwijay-hermes/scripts/check_free_keys.py            # zote
python3 mwijay-hermes/scripts/check_free_keys.py groq gemini  # baadhi tu

Haisomi wala kuchapisha thamani ya key — inaonyesha tu SAWASAWAA / IMEKWAMA na sababu (401, 429 = rate limit, n.k.).

7) Mambo ya kukumbuka (usije ukaungua)

  • Usiweke keys kwenye Git. .env iwe kwenye ~/.hermes/, na hakikisha haiwi kwenye repo (angalia .gitignore).
  • Free tiers hubadilika bila taarifa. Leo model fulani ni bure, kesho inaweza kuwa haipo. Ndiyo maana mnyororo wa fallback ni muhimu kuliko kutegemea provider mmoja.
  • Rate limits ndio adui, si bei. Groq 30 RPM, Cerebras 30 RPM (na 8K context kwenye free), SambaNova 20 req/siku. Kwa agent inayofanya kazi nyingi mfululizo, unahitaji providers wengi kwenye mnyororo.
  • Usitumie keys za watu wengine (tazama onyo juu). Zaidi ya sheria: hizi keys hufutwa mara moja, na hivyo “akili yako” itakuwa ikiisha ghafla bila sababu.
  • Fuatilia matumizi. Inception inakupa tokeni milioni 100 mara moja (si kila mwezi); NVIDIA na Hugging Face hutoa mikopo isiyorudi.
  • Usizidishe akaunti nyingi kupita kiasi. Kufungua akaunti chache za bure ni kawaida; kufungua mamia ili kukwepa viwango kunakiuka sheria za providers wengi na kunaweza kufunga akaunti zako zote.
