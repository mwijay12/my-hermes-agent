# Research & Learning (Mwijay)

## When to use
- Mwijay anataka kujifunza kuhusu tech mpya (AI models, GitHub repos, tools)
- Research ya haraka: "nifanyie research kuhusu X"
- Kuelewa maana ya repo/model/tool (mf. kimi-k3-in-c)

## Workflow
1. **Tafuta kwanza:** tumia web search / GitHub / docs — usitegemee memory pekee kwa taarifa mpya.
2. **Fupisha kwa Swahili:** maana rahisi kwanza, halafu technical detail.
3. **Tathmini kwa PC yake:** je, inafaa kwa Windows 8–16 GB RAM, <1 TB disk? Ni bure? Ni polepole?
4. **Toa hitimisho:** inafaa / haifai / inafaa kwa majaribio tu — na sababu.
5. **Hifadhi:** ukijifunza jambo muhimu, liandike kwenye MEMORY.md.

## Rules
- Taja vyanzo (links) unapotumia taarifa kutoka web.
- Kuhusu Kimi K3: 1.56 TB disk, 8.24 GB RAM min, 5–26 s/token — research tu, sio matumizi ya kila siku.
- Usitumie taarifa za zamani kama zimebadilika — tafuta upya.
